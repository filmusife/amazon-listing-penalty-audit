# 7 项判定标准

只在执行体检时读。每项输出：判定（通过 / 不通过 / 高风险 / DATA_MISSING）+ 证据 + 粘贴改法。

## 1. 尺寸 / 重量 / 属性不一致

**不通过，若出现任一：**

- 属性栏、A+、五点、包装、主图标注，有两套及以上尺寸
- 同一父体下不同子 ASIN 尺寸不同，但变体主题不是 Size
- Item Weight 为空
- Style / Material 等字段是脏值（如 Style=`NICE`）或各颜色互相矛盾

**通过：** 四处尺寸逐字相同，重量已填，材质与可见实物一致（壳体塑料就不要只写 Stainless Steel）。

**改法：** 给一套统一字段表，四个（或全部）子 ASIN 只改 Color/Size 维度，其余复制。尺寸优先用主图标注或用户实测；误差声明阈值 ±0.3 inch。

## 2. 变体主题错配

**不通过：** 主题是 Color 但子体实际差的是尺寸/材质/容量；或主题是 Size 实际只是颜色。

**主题通过、内容不通过：** 主题正确，但标题/五点/属性未对齐（旧文案和新文案并存、橙色机写 black design、笔误）。这时 **不要拆组**，对齐文案。

**通过：** 主题 = 真实差异维度，且所有子体共用同一套标题模板和五点，只替换变体词。

英雄子体若已有稳定小类排名，不要为了“更完整”去改它的标题。

## 3. Browse node 多选或错选

**通过：** 前台面包屑叶子类目与产品类型一致，且该类目前列竞品是同类产品。

**不通过：** 叶子类目明显跑偏（磨豆机挂到户外、支架、配件）。

**DATA_MISSING：** 后台到底挂了几个节点。前台只能看到主路径。

**改法：** 主节点只留最精确的 1 个；最多再加 1 个真正相关的第二节点。删除无关节点。不要为了“多曝光”多挂。

## 4. 图片 ALT 空白或中文

**不通过：** colorImages 无有效 altText；A+ 图 alt 为空/中文/只有 coffee grinder 这种单词。

**改法：** 必须先看图再写 ALT。一句英文，产品名 + 可见功能 + 材质或场景 + 颜色。不堆词，不用竞品品牌和夸大词。按 **每个 ASIN 的槽位顺序** 输出，因为不同颜色图序可能不同。

主图合格就不要重拍主图。

## 5. Search Terms 竞品品牌 / ASIN

前台标题五点没有品牌词 ≠ 后台 ST 干净。ST 读不到就整段替换。

**ST 只放：** 前台未出现的同义词、次场景、原料长尾、操作同义词。

**ST 禁止：** 竞品品牌、任何 ASIN、标题/五点已有词、夸大词、与实物不符的品类词（刀片机写 burr）。

美国站 ≤249 字节，空格分隔，全小写。四个颜色共用一段 ST（颜色词已在标题末尾）。

## 6. 描述 / 图片 vs 实物

**高风险 / 不通过：** 图与文数字打架（12 cups vs 3 cups，63 dB vs 60 dB，可拆碗 vs 一体碗）；尺寸图和属性栏不是同一套数。

**改法：** 选一个可测量口径，所有位置一起改。杯数优先跟容量克数和主图，不要用虚高杯数。噪音没有第三方报告时用更高（更保守）的 dB，并写 in-house test。配件图不要标 GIVE AWAY。

未实测重量/功率就不要填。

## 7. 30 天改价超过 5 次

用 Keepa / 同类价格曲线。近 30 天改价 >5 次 = 不通过。锯齿价（$24.99/$26.99 来回）即使没超 5 次也要警告。

**改法：** 锁一个基础价；让价用 coupon，不改 list price。不要为划线价把基础价抬上去再降下来。同一父体子体供货价保持一致。
