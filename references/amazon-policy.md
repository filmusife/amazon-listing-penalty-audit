# 美国站 Listing 政策底线

写任何标题、五点、Item highlights、图片 ALT、A+、Search Terms 之前先读本文件，并打开下面的 Seller Central 页面。

本文件是上次核对过的 **US** 快照，**不是永久真理，也不是全球站点真理**。拉到的现行帮助页覆盖这里的条款。拉失败则沿用本快照，并在报告标 `POLICY_FETCH_FAILED`。

非美国站：先开该站点 Seller Central 对应帮助页。当地规则覆盖本快照。拉不到则继续用本快照体检，并标 `MARKETPLACE_UNVERIFIED`。不要把 US 的 75 字符标题上限默认套到所有站点。

不要把 2024/2025 第三方博客或旧体检稿当成现行规则。

## 保修 / 保证放哪

**不能**写进标题、五点、Product Description、图库、A+、ALT、Search Terms。

Seller Central 五点的 Prohibited content 明确禁止 **Guarantee information**，示例包括 Full refund、If not satisfied send it back、Unconditional guarantee with no limit。标题也禁止 `100% quality guaranteed` 这类促销保证。图片禁止 warranty / guarantee 徽章和对应英文词。

保修只进 **Warranty 文档 / warranty 专用属性**。思考区可以告诉用户去哪个后台字段填；粘贴块里不要出现 warranty、guarantee、money-back、2-year manufacturer's warranty。

## 标题（现行 US，新媒体类目）

- 新上架或你主动改标题：≤ **75 字符（含空格）**。超长标题可能被自动改正或搜不到。
- 溢出卖点进 **Item highlights**：≤125 字符，逗号分隔短语，不要写成句子。
- 禁止促销语：free shipping、100% quality guaranteed、hot item、best seller。
- 禁止字符：`! $ ? _ { } ^ ¬ ¦`。`~ # < > *` 只能当型号或计量，不能当装饰。
- 同一词（含品牌）最多两次；冠词/介词/连词除外。
- Title Case，不要全大写或全小写。
- 顺序：品牌、品类、关键属性，颜色/尺寸/件数放最后。子体标题带变体词，父体不带。
- 已有长标题若仍正常展示、小类排名稳定、且 **没有政策违规**：思考区说明当地字数风险，英雄子体可暂不改。一旦含 warranty / guaranteed / 主观夸大 / 禁用符号 / 明显抑制，必须按该站点现行上限重写。

## 五点

- 至少 3 条独特卖点；常见长度约 10–255 字符（以类目模板为准）。
- 首字母大写；写成短语，**句末不加句号**；不要整条 ALL CAPS；不用 【】★ emoji ™ ®。
- 禁止：Guarantee information；eco-friendly / environmentally friendly / anti-microbial / anti-bacterial；无依据的 bamboo / soy 宣称；ASIN；N/A TBD；公司网址电话；同一事实在多条重复；已有独立属性的面料/护理/原产国（按类目模板）。
- 主观比较（best、#1、better than、quieter than、guaranteed）没有包装+可验证证据就不要写。

## 图片 / A+

任何产品图都禁止 warranty、guarantee、促销、认证徽章，以及 mimic Amazon 的图形。禁止字符串包括但不限于：warranty、guarantee、best、amazon、prime、fda、certified、coupon、free、sale。

主图：白底、产品占比、无文字徽章。特征图可以有尺寸/功能标注，但标注数字必须和属性/五点一致，且不能变成促销章。

## 宣称

政策覆盖 PDP 全部字段、图片、包装、A+。性能、成分、产地必须可验证。无证据不要写 best / 100% / guaranteed / 病症 / FDA / Made in USA / eco-friendly。品类特有禁词读 [category-overlays.md](category-overlays.md) 对应节。

## Search Terms

美国站 `generic_keywords` **小于 250 字节**。超限整段不索引。

只放前台没有的同义词、缩写、次场景。不放品牌（自己的和竞品的）、ASIN、best/cheapest、on sale、脏词。

## 权重怎么用这些规则

合规不是终点。政策清掉违规词之后，用腾出的位置写 **可验证、可筛选、能被 Rufus 引用、能降低退货** 的信息：规格、材质、箱内配件、真实功能、使用场景和受众。发现层奖励的是完整属性和一致事实，不是堆保证口号，也不是把同一个关键词连写三遍。
