# 文案规则

写改法时读。先过官方政策，再补发现层。不要为了堆 A9 词牺牲合规。写字段时同时读 [rufus-cosmo.md](rufus-cosmo.md)。品类机制词、单位、禁写功效只取 [category-overlays.md](category-overlays.md) 匹配节。

## 每条建议的结构

用户会把代码块整段贴进 Seller Central。因此：

1. 块前标题 **只用字段名**：`标题（Navy, Size M）`、`Item highlights（Navy, Size M）`、`五点（全变体共用）`、`属性（全变体共用）`、`图库 ALT（White）`、`A+ ALT（父体共用）`、`Search Terms`。
2. 禁止在标题或块内写“可复制”“可粘贴”“paste-ready”。
3. 代码块里 **只有** 目标语言原文（美国站默认英文）。
4. 代码块正上方用 **思考** 说清楚：依据哪条 Seller Central 规则；当前稿错在哪或弱在哪；服务哪一层（政策 / COSMO 关系 / Rufus 可引用事实 / Lexical 同义词）。禁止写「堆 A9 词」。

错误标题：`可粘贴：标题（Blue）`

正确示例（思考在块外，块内只有标题）：

### 标题（Navy）

**思考：** 现标题含主观夸大和超字数风险。按现行标题政策改成品牌+品类+已验证属性+变体词，把场景短语放到 Item highlights。

```
BRAND Product Type, Key Spec, Navy
```

## 政策闸门（写之前过一遍）

对照 [amazon-policy.md](amazon-policy.md)。出现任一项就先改文案，再谈优化：

- warranty / guarantee / money-back / 100% quality guaranteed
- best / #1 / 无证据的绝对词 / 点名竞品
- eco-friendly / anti-bacterial / 无证据认证或功效
- 标题禁用符号、整段 ALL CAPS、五点句末句号+整条大写
- 图上 warranty / prime / certified 徽章
- 竞品品牌或 ASIN
- overlay 里列出的品类错词

保修不写进 PDP 营销字段。思考区写去 Warranty 属性填什么；五点腾出来写规格、材质、配件、使用边界。

## 标题

- 品牌 + 品类 + 1–2 个已验证关键属性 + 变体词（颜色/尺寸/口味放最后）
- 新写或因违规而重写：美国站 ≤75 字符（含空格）；其他站点按当地规则
- 装不下的材料、场景、配件：放到 Item highlights（≤125，逗号短语）
- 英雄子体标题已合规、小类排名稳定、且未触发抑制：默认不改标题，思考区写“不动”以及为什么不动。不要输出带“不要改”的标题块
- 英雄标题一旦违规：必须改，排名好也不能留
- 其他子体：整段换成英雄子体模板，只替换变体词
- 不用【】★ best #1 竞品品牌，不用 overlay 禁止的机制词

## Item highlights

标题按站点上限重写时必须给。逗号分隔短语，不是句子，不重复标题里已经有的词，不放 warranty / 促销。

## 五点

- 全部子体 **一字不差**，不要在共用五点里写死某个颜色/尺码/口味
- 至少 3 条，每条独特；约 10–255 字符；首字母大写；句末不加标点
- 建议覆盖（有证据才写）：是什么/给谁用、可测量规格、关键功能、使用场景、箱内配件或使用边界。一条一个问题，服务 Rufus 引用，不要管道符堆 A9 词
- 去掉装饰符号和与主图冲突的虚数
- 可量化的用克数、英寸、功率、成分百分比（有依据才写）
- 图上或 FAQ 已有的限制（不可湿用、不可机洗、不兼容某接口）五点要写明，降低退货
- 不写 warranty / guarantee / 退款承诺
- 粘贴块 = bullet 正文，不要 `Bullet 1 改成：` 这种中文前缀

## 属性

常见脏字段与修法（值要按实物，不要抄例子）：

| 字段 | 不要 | 要 |
|---|---|---|
| Style | NICE、随意形容词 | 与实物相符的真实 style |
| Material | 只写金属但壳体是塑料；只写 Cotton 但混纺 | 可见/成分表上的真实材质 |
| Size | Large（和尺寸筛选打架） | 容量、服装尺码名或真实 size 名 |
| Included Components | 件数不对、把不可拆部件写成配件 | 整机/整件 + 真实配件清单 |
| Capacity | 虚高杯数、营销次数 | 可称重或可量体积的口径 |
| Item Weight | 抄容量 oz、留空 | 称完再填 |
| Warranty | 写进标题/五点 | 只填 Warranty 专用字段 |

同一父体除变体维度外全部复制。粘贴块按 `字段名: 值` 输出，不要附“所有颜色都改”。填满可筛选字段，是合规之后对自然流量最稳的一步。

## 图库 ALT

一句，匹配站点语言。美国站英文约 120–180 字符：

`{品牌} {变体词} {看得见的产品} with {材质或关键零件} for {图中场景}`

按该 ASIN 槽位输出，键名只用 `MAIN:` `IMG2:` `IMG3:` … 后面直接跟句子。变体图序不同就按实图写，不要套英雄子体顺序。

ALT 必须描述 **当前仍在线的画面**。若思考区要求换图，另开代码块，标题写 `图库 ALT（{变体}，换图后）`。不要写 warranty / best / 竞品品牌。

## A+ ALT（必出）

每个已分析的 A+ 图都要有一句 ALT，即使建议是“A+ 图不用换”。

- 按页面模块从上到下、模块内从左到右编号：`A+1:` `A+2:` `A+3:` …
- 句式与图库 ALT 相同：品牌 + 可见内容 + 材质或功能 + 不要夸大词
- 装饰图标也要短句，不要留空
- 父体共用 A+：出一块 `A+ ALT（父体共用）`
- 某模块随子体变化：再按 ASIN 各出一块，块内仍只有 `A+n:` 句子
- 完整清单必须写进报告文件；聊天在第 4/8 项不通过或 A+ 被分析时，至少给出 A+ ALT 块

## Search Terms

美国站 <250 字节，空格，小写，不重复。用脚本核字节。

放：前台没有的同义词、次场景、材质/原料长尾、操作或用途词。

不放：标题五点已有词、竞品品牌、ASIN、best、warranty、overlay 禁止的机制词。

同一父体通常共用一段。粘贴块里只有那一行小写词；字节数写在思考区。

## A+ 文案

规格块数字必须和属性栏、主图/尺码图标注相同。修对比表笔误。FAQ 不要承诺前台没证据的功能，也不要写 warranty。

对比表、FAQ 的粘贴块只放将要填进模块的原文，不要放“把 No 改成 Yes”这种操作说明。

## 合规之后还要做的权重优化

细节和 COSMO 关系短表见 [rufus-cosmo.md](rufus-cosmo.md)。这里只留写字段时不能忘的动作：

- **属性优先于再改 Search Terms。** 填满筛选器和 discovery 字段：weight、dimensions、material、capacity/size、included components、intended_use、target_audience、occasion、item type、care、compatibility。空字段 = Rufus 无法回答。
- Browse node 只留最精确叶子类目。
- 全变体共用一套干净标题模板和五点，减少 COSMO 分裂信号。
- 标题：品牌 + 品类 + 1-2 个已验证规格；75 字符还装得下再加受众或场景。不要关键词汤。溢出进 Item highlights。
- 五点一条回答一个买家问题（是什么/给谁、规格、功能、场景、配件或边界）。不要管道符堆词，不要复述标题。
- A+ 当知识库：正文、对比表、overlay 数字必须对当前子体为真；overlay 会被 OCR。
- ALT 描述可见内容，给图搜和对话层一个短句源。
- ST 只补未索引同义词 + 少量意图短语，不抄标题，不放品牌/ASIN/best/warranty。
- 全场数字同一口径，用可测量或更保守的值，降低 INAD。
- 主图白底无徽章；特征图写规格/配件/边界，不写 premium/warranty。
- 不为堆词牺牲可读性。Amazon 可能改写不合规五点，主动写对比被改写更稳。
- 现网若无独立 Q&A 模块，不要把「去种 Q&A」当成必须改法。
