# 可粘贴文案规则

写改法时读。目标是合规 + 索引补充，不是堆词。

## 标题

- 品牌 + 核心品类 + 2–4 个已验证卖点 + 主场景 + 变体词（颜色/尺寸放最后）
- 英雄子体已有稳定小类排名：默认不改标题
- 其他子体：整段换成英雄子体模板，只替换变体词
- 不用【】★ best #1 竞品品牌

## 五点

- 四个（全部）子体 **一字不差**，不要在共用五点里写死某个颜色
- 去掉装饰符号和 12 cups 这类与主图冲突的虚数
- 可量化的用克数、英寸、dB（有依据才写）
- 安全锁、碗是否可拆、不支持湿磨：图上或 FAQ 有的，五点要写明，降低退货
- 每条都能在图或实物上对上

## 属性

常见脏字段与修法：

| 字段 | 不要 | 要 |
|---|---|---|
| Style | NICE、随意词 | Compact / 与实物相符的真实 style |
| Material | 只写 Stainless Steel 但壳体是塑料 | ABS, Stainless Steel（按实物） |
| Size | Large（和尺寸筛选打架） | 容量或真实 size 名 |
| Included Components | 1 BOWL（碗不可拆时） | 整机 + 真实配件清单 |
| Capacity | 12 cups | 70 grams 这类可称重量 |
| Item Weight | 抄容量 oz | 称完再填 |

同一父体除变体维度外全部复制。

## ALT

一句英文，约 120–180 字符：

`{品牌} {颜色} {看得见的产品} with {材质或关键零件} for {图中场景}`

按槽位输出。White/其他颜色图序不同就按该 ASIN 实图写，不要套英雄色顺序。

图上有 3 cups / 60 dB 时，ALT 先跟画面；若计划改图，在报告里写“改图后 ALT 同步改成 …”

## Search Terms

美国站 ≤249 字节，空格，小写，不重复。

放：前台没有的同义词（mill / blade / silent）、次场景（apartment camping）、原料长尾、冲煮法（pour over aeropress moka）、操作词（automatic rotary coarse fine）。

不放：标题五点已有词、竞品品牌、ASIN、burr（若是刀片机）、wet grinding、best。

四色共用一段。输出时写明字节数。

## A+

规格块数字必须和属性栏、主图标注相同。修对比表笔误。FAQ 不要承诺前台没证据的dishwasher / 多国电压 / 湿磨。
